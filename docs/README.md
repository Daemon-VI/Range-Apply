# Career Context Documentation

Human-readable career context files for CareerOS agents.

## Career Files

| File | Description |
|------|-------------|
| [PROFILE.md](career/PROFILE.md) | Identity, education, contact, positioning |
| [MASTER_RESUME.md](career/MASTER_RESUME.md) | Canonical factual resume |
| [SKILLS.md](career/SKILLS.md) | Categorized skill inventory |
| [EXPERIENCE.md](career/EXPERIENCE.md) | Experience entries |
| [ACHIEVEMENTS.md](career/ACHIEVEMENTS.md) | Verified achievements |
| [PREFERENCES.md](career/PREFERENCES.md) | Career/application preferences |
| [TRUTH_RULES.md](career/TRUTH_RULES.md) | Hard constraints for all agents |
| [CAREER_BRAIN.md](career/CAREER_BRAIN.md) | Career Brain service documentation |

## Project Files

See [projects/PROJECT_INDEX.md](projects/PROJECT_INDEX.md) for the full project index.

## Usage

Agents should read `RIBHU_CAREER_CONTEXT.md` first, then only the specific files needed for their task. For programmatic access, use the CareerBrainService API instead of reading markdown files directly.
